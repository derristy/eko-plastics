# Уровень 1 — Frontend

Вёрстка главной и Contact us по макету.

Демо: https://eko-plastics.derristy.com

HTML, CSS и ванильный JS, без сборщика. Шрифт Inter с Google Fonts.

Карточки отзывов плавно увеличиваются при наведении, ссылки-заглушки без подчёркивания и с тенью на ховере. Бургер-меню включается до 1024px: иконка превращается в крестик, панель раскрывается с анимацией, закрывается по клику вне меню, по Esc и после перехода по ссылке.

Мобильной версии в макете нет, сделал по логике планшетной.
