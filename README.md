## Что в каждом уровне

**Первый.** Вёрстка двух страниц макета на чистом HTML, CSS и JS без сборщика. Карточки отзывов увеличиваются при наведении, ссылки-заглушки без подчёркивания и с тенью на ховере, бургер-меню с анимацией включается до 1024px. Мобильной версии в макете не было, сделал по логике планшетной.

**Второй.** Два PHP-скрипта: первый подтягивает цены из прайса в файл импорта и заливает строки цветом, второй собирает из результата XML-фид для маркетплейсов. Прямой связи между файлами нет — артикулы из разных систем, поэтому позиции сопоставляются по модели и числовому параметру. Фид пишется потоково: 12 тысяч строк за 5 секунд при 2 МБ памяти.

**Третий.** Laravel: форма с валидацией и защитой от спама без капчи, заявка уходит в SalesDrive, оттуда контакт передаётся в Діловод в группу «Клієнти». Отправка идёт через очередь с повторными попытками, поэтому заявка не теряется, если внешний сервис недоступен. Доступность обоих API проверяется по расписанию, при падении приходит сообщение в Telegram.

**Четвёртый.** Вариант C — сниппет для MODX: форма, серверная валидация, сохранение заявок через xPDO и передача в SalesDrive. MODX выбран потому, что файл «Імпорт» из второго уровня оказался выгрузкой именно из MODX, то есть это рабочая CMS заказчика.

## Развёртывание

**Первый уровень** — статика, сборка не нужна, достаточно залить содержимое папки в корень сайта.

**Второй уровень** — нужен PHP 8.3 и Composer:

```
cd level-2-excel-xml
composer install
php update-prices.php
php generate-xml.php
```

Результаты появятся в `output/`.

**Третий уровень** — PHP 8.3, Composer, MySQL:

```
cd level-3-integration
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

В `.env` нужно заполнить доступ к базе и ключи API. Чтобы заявки уходили в CRM, дополнительно запускается воркер очереди `php artisan queue:work` и планировщик `php artisan schedule:run` по крону.

**Четвёртый уровень** — сайт на MODX 3. Папка `core/components/ekoform` копируется в `core/components`, файл `install.php` кладётся в корень и запускается один раз: он создаёт таблицу, сниппет, чанк и настройки. Дальше форма выводится вызовом `[[!ekoForm]]` в любом ресурсе.

## Доступы

Логины и пароли к тестовым аккаунтам SalesDrive, Діловод и к админке MODX отправлены в Telegram — в публичном репозитории они не хранятся.
